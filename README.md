# HOKEMI

VIVANTに着想を得た、1人用のブラウザ・ミニゲーム集です。タイトル画面の「はじめる」からプレイできます。PC・スマホ対応。サーバー、アカウント、APIキーは不要です。

## HTMLファイルを直接開いて遊ぶ

`npm run build` は、通常の公開用ファイルに加えて **`dist/play.html`** も生成します。このファイルにはゲームのコード・スタイル・地図をすべて同梱しており、ダウンロードしてChromeやEdgeなどのブラウザで直接開けます。サーバー起動やインターネット接続は不要です。チャット内のファイルプレビューで表示エラーが出る場合も、ファイルを保存してブラウザで開いてください。

`dist/index.html` は通常のWeb公開用です。ファイルを直接開くときは `play.html` を使ってください。

## GitHub Pagesでスマホに公開する

`docs/index.html` に、必要なコード・地図・スタイルをすべて含めた公開用ゲームを置いています。

1. GitHubのリポジトリ設定で **Settings → Pages** を開きます。
2. **Source: Deploy from a branch** を選びます。
3. **Branch: main**、フォルダ **/docs** を選び、**Save** します。
4. デプロイが完了すると、Pages画面に表示されるURLをスマホのSafariやChromeで開いて遊べます。

ゲームを修正したときは、`npm run build:pages` で `docs/` を更新し、ソースコードと一緒にコミット・pushしてください。Pages有効化後は、`main` の `docs/` 更新で公開版が更新されます。リポジトリの公開範囲や契約によりPagesの利用条件が異なります。

## 開発

Node.js 24 と npm を使用します（この環境では Node.js 24.19.0 で確認）。

```bash
cd /workspace/hokemiii
npm ci
npm run dev -- --port 5173
```

```bash
npm run build  # 型検査、本番用ビルド、ブラウザで直接開けるdist/play.htmlを生成
npm run build:pages  # GitHub Pages向けのdocs/も更新
npm test       # Chromiumで実際の操作、8種類の連続クリア、加速、失敗、記録保存を検証
npm run preview -- --port 4173  # 本番用ビルドを確認
```

テストは `/usr/bin/chromium` を使います。他の環境では `CHROMIUM_PATH` で実行ファイルのパスを指定してください。ブラウザが未導入なら、Playwright公式手順でChromiumを導入してから指定してください。

## ルール

- 全8種類が毎周ランダムな順番で1回ずつ出現します。周回の境目でも同じゲームは連続しません。
- **1ミスでプレイ終了**。時間切れも終了です。「もう一度、潜入する」から即リスタートできます。30クリアまでは「任務失敗」、31クリア以上では「任務成功」と表示します。31クリアでゲームは止まらず、ミスするまでステージが続きます。
- 失敗後の結果画面では、問題の正解や間違いの場所を表示しません。
- 8クリアで1周。2周目1.2倍、3周目1.4倍、4周目1.6倍と加速し、最大2.4倍です。動きや制限時間、記憶時間、相手のノックも速くなります。
- スコアはクリアしたステージ数。自己最高記録はブラウザの `localStorage` に保存します。同じ端末・ブラウザで維持されます。ストレージが使えない場合もプレイ可能です。
- 失敗画面は「あなたは〇〇です」と表示します。称号はクリア数に応じて、0〜5：KEKKAN、6〜10：SENPAN、11〜15：IPPAN、16〜20：MIKAN、21〜30：BEPPANです。31以上では称号の代わりに「任務成功」を見出しに表示します。
- 「記録を共有する」は端末の共有機能、またはクリップボードを使用します。使用できない場合はコピー用テキストを表示します。オンラインランキングはありません。
- 一時停止ボタンまたは P / Esc で停止・再開。別タブへの移動時も自動停止します。

| 任務 | 操作・内容 |
| --- | --- |
| 刺せ | 横から飛ぶバナナにナイフを1回だけ投げる。バナナの移動速度は従来の約1.4倍で、周回時にはさらに加速する。画面タップ / 投げる / Space。 |
| 見つけろ | 日本地図のみ出題。四国・滋賀県・佐渡島・沖縄のいずれかが消える異変を探す。沖縄も地理的な位置と共通の縮尺で左下に収まるよう、日本列島全体を表示。開始時から間違いがある地図を直接タップして答える。選択肢・候補マーカー・記憶時間は設けない。大学キャンパスの問題は出題しない。 |
| 伝えろ | 5桁の接触コード。自分→相手（自動）→自分→相手（自動）→自分。各桁は最初2〜5回、周回とともに増えて最大9回までの1桁。制限時間は初期16秒。入力済み回数の表示はなく、自分で数えてノックする。照合に成功すると扉が開く。多く叩くと失敗。画面タップ / ノック / Space。 |
| よけろ | 4列の縦レーザーは左右に移動して回避。下段を横切るレーザーはジャンプで避ける。画面の左右 / 左右ボタン / ←→で移動し、画面中央 / ジャンプボタン / ↑・Spaceでジャンプ。周回とともに予告と発射が速くなり、縦レーザーは2列同時になる。 |
| 狙え | 赤い心臓のすぐ横、白い照準を狙って1発撃つ。照準をタップ。PCは矢印キーで照準を動かしてSpaceでも操作可能。 |
| 覚えろ | 奥行きのある階段の記録写真を記憶し、床・整備士の服・時計・人数について4択で回答。整備士はスパナと作業帽で見分けられる。写真はオリジナルイラスト。 |
| 撒け | 繁華街を3列で走り、人混みを回避する。左右タップ / 左右ボタン / ←→。逃げ切ると追跡者が「失尾しました」。 |
| 食べろ | 黄色い和服の大男がチャーハン10人前を食べる。画面タップ / 食べる / Spaceを10回。回数やカウントアップは表示せず、皿の残りが減っていく。長押しによる自動入力は無効。 |

## 構成

- `src/main.ts`：画面遷移、ランダム出題、周回、記録、一時停止、共有。
- `src/games.ts`：8種類のゲーム、描画、入力・成功判定。
- `src/draw.ts`・`src/audio.ts`：Canvasの描画と効果音。
- `src/style.css`：PC・スマホの表示。
- `src/data/japan.json`：同梱の簡略化した地図。実行時の外部取得はありません。
- `tests/game.spec.ts`：Playwrightの機能テスト。

作品の公式素材・音楽・俳優の肖像は使用していません。地図の出典・利用条件は [THIRD_PARTY.md](THIRD_PARTY.md) を参照してください。

`dist/` は一般の静的ホスティング、`docs/` はGitHub Pagesのブランチ公開に使用できます。初回のPages有効化はGitHubの設定画面で行います。
